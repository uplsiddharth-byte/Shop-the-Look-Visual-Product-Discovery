Upload an outfit photo: the app detects each garment or accessory, matches it to a product catalog, says whether the exact product exists, and explains every recommendation.

Source code, technical document and setup: https://github.com/uplsiddharth-byte/Shop-the-Look-Visual-Product-Discovery

First start-up downloads about 3 GB of data and 2 GB of models, so a cold start takes a few minutes. Free CPU hardware: expect several seconds per photo.
